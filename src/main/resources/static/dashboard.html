Stage Reference

1
FILTER_START
Filter method body begins. Very first thing that runs — before anything Spring MVC does.
Recorded by: RequestTracingFilter
2
REQUEST_RECEIVED
requestId assigned, request/response wrapped in caching wrappers, trace saved to store.
Recorded by: RequestTracingFilter
3
INTERCEPTOR_PRE_HANDLE
Inside DispatcherServlet, before controller. Handler method name captured here. Return false to abort the request.
Recorded by: LifecycleInterceptor#preHandle
4
CONTROLLER_EXECUTION
Recorded at the exact moment the @RestController method body starts. Uses AOP @Around on @RestController — the only hook precise enough to capture this.
Recorded by: ControllerTraceAspect
5
INTERCEPTOR_POST_HANDLE
After controller returns, before Spring writes the response. NOT called if controller throws — use afterCompletion for guaranteed cleanup.
Recorded by: LifecycleInterceptor#postHandle
6
INTERCEPTOR_AFTER_COMPLETION
Always called — success or exception. Exception info captured here if non-null. Mirror of preHandle: every request that passed preHandle gets this.
Recorded by: LifecycleInterceptor#afterCompletion
7
RESPONSE_SENT
Filter's finally block. Cached response bytes flushed to the wire. totalExecutionMs computed here as wall-clock time from FILTER_START.
Recorded by: RequestTracingFilter (finally)

Legend & Column Reference

HTTP Method Badges

GET Read resource, no body
POST Create resource, has body
PUT Replace resource
PATCH Partial update
DELETE Remove resource

HTTP Status Badges

200 2xx — Success
302 3xx — Redirect
404 4xx — Client error
500 5xx — Server error
— In-flight / not yet set

Table Columns

Request ID
UUID assigned by filter at request entry. First 8 chars shown. Click row to expand full detail.
Method
HTTP verb captured at filter entry.
Path
Request URI (no query string).
Status
HTTP response status. "—" means request is still in-flight.
Handler
ClassName#methodName of the matched @RestController method. Set in preHandle via HandlerMethod introspection.
Time
Wall-clock ms from FILTER_START to RESPONSE_SENT (filter finally block).
Stages
Number of lifecycle stages recorded out of 7. <7 means request still in-flight or was aborted.
